**Rule ID:** RES-006

**Description:** `service.criticality` uses a valid enum value

**Rationale:** The `service.criticality` resource attribute indicates the operational importance level of a service. Using standardized enum values enables automated prioritization of alerts, incidents, and resource allocation decisions across heterogeneous environments. Without consistent values, tooling cannot reliably compare or act on criticality levels. Defined in the [OpenTelemetry Semantic Conventions for Resources](https://opentelemetry.io/docs/specs/semconv/resource/service/).

**Target:** Resource

**Criteria:** If the `service.criticality` resource attribute is present, its value MUST be one of the following enum values: `critical`, `high`, `medium`, `low`.

**Examples:**

- "Resource attribute `service.criticality` is set to `mission_critical` instead of a valid enum value."
- "Resource attribute `service.criticality` is set to `HIGH` (uppercase) instead of the expected lowercase `high`."

**Impact:** Normal
